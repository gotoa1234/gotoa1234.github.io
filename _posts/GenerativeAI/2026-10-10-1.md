<h1>第二部分：解決 ABI & CUDA build 不一致問題</h1>


<h2>Step 1：解決目標</h2>
以我的電腦為例，目前已定位出錯誤原因在版本不一致問題，因此目標是將 torchaudio 升級到 13.0 讓兩者版本一致

``` Markdown
torch       2.14.0        → CUDA 13.0
torchvision 0.29.0
torchaudio  2.11.0+cu128  → CUDA 12.8
```

<br/><br/>


<h2>Step 2：使用高權限訪問容器</h2>
要移除跟安裝容器內軟件，需要先提升權限，因此使用以下進入容器內

``` Powershell
docker exec -u 0 -it 您的容器名稱或ID bash
```

<br/>補充：權限不足後續執行會出現這樣的錯誤(因此要先用 root 權限)：
<br/><img src="/assets/image/GenerativeAI/2026_10_10/001.png" width="100%" height="100%" />
<br/><br/>
<br/>
<br/>然後進入 ComfyUI 的容器目錄下

``` shell
cd /comfy/mnt/ComfyUI
```

<br/><br/>


<h2>Step 3：刪除舊的版本</h2>
然後輸入以下指令，進行刪除

``` Powershell
/comfy/mnt/venv/bin/python -m pip uninstall torchaudio
```

<br/>當詢問 Proceed 時，輸入鍵盤 Y 表示同意刪除
<br/><img src="/assets/image/GenerativeAI/2026_10_10/005.png" width="100%" height="100%" />
<br/><br/>


<h2>Step 4：安裝升級版本</h2>
然後輸入以下指令，進行安裝升級 CUDA 13.0 版本

``` Shell
/comfy/mnt/venv/bin/python -m pip install torchaudio==2.11.0+cu130 --index-url https://download.pytorch.org/whl/cu130 --no-deps
```

<br/>安裝需要使用到網路，會一些時間
<br/><img src="/assets/image/GenerativeAI/2026_10_10/006.png" width="100%" height="100%" />
<br/><br/>

<h2>Step 5：重新啟動容器 & 檢查</h2>
安裝完成後，進行 ComfyUI 容器重啟
<br/><img src="/assets/image/GenerativeAI/2026_10_10/007.png" width="100%" height="100%" />
<br/><br/>
<br/>然後輸入以下指令，進行檢查：

``` Shell
/comfy/mnt/venv/bin/python -c "import torch, torchaudio; print('torch:', torch.__version__); print('CUDA:', torch.version.cuda); print('torchaudio:', torchaudio.__version__)"
```

<br/>
<br/>可以檢查輸出發現版本，兩者版本一致，都升到 CUDA 13.0

``` Markdown
torch: 2.14.0+cu130 -------> 正確
CUDA: 13.0
torchaudio: 2.11.0+cu130 --> 正確
```
